# ☂️ ربات مدیریت گروه و چت‌بات چتر (Chatar Bot)

یک ربات تلگرامی پیشرفته، هوشمند و فول امکانات برای **مدیریت کامل گروه‌ها** و **پاسخ‌دهی هوشمند (چت‌بات)** که با زبان پایتون (`pyTelegramBotAPI`) و دیتابیس `SQLite` توسعه یافته است.

---

## ✨ ویژگی‌های کلیدی

- 🤖 **چت‌بات هوشمند اختصاصی:** امکان یاددهی کلمات و پاسخ‌های سفارشی به ربات با پاسخ‌دهی تصادفی.
- 🛠️ **پنل مدیریت پیشرفته گروه:** کنترل سریع گروه‌ها با دکمه‌های شیشه‌ای و سوئیچ‌های روشن/خاموش.
- 🛡️ **قفل‌های امنیتی هوشمند:**
  - ⛔ ضد فوروارد (Anti-Forward)
  - 🔗 ضد لینک و آیدی (Anti-Link)
  - 🤖 ضد ربات (Anti-Bot)
  - 📨 ضد اسپم (Anti-Spam)
- ⚠️ **سیستم اخطار و سانسور:** شناسایی خودکار کلمات ممنوعه، پاک‌سازی پیام و ثبت اخطار برای کاربر (با قابلیت حذف اخطار توسط مدیران).
- 👑 **مدیریت اعضای ویژه (VIP) و القاب:** معاف‌سازی اعضای ویژه از قفل‌ها و اعطای لقب اختصاصی به کاربران.
- 💥 **پاک‌سازی سریع پیام‌ها (Purge):** حذف دسته‌جمعی پیام‌های اخیر گروه (تا ۱۰۰ پیام) یا تعداد دلخواه.
- 📦 **سیستم بکاپ و بازیابی کامل (Backup & Restore):** دریافت بکاپ کامل از دیتابیس SQLite و بازیابی آن تنها با یک دستور بدون از دست رفتن حافظه ربات.

---

## 📖 راهنمای دستورات

### 👤 دستورات پیوی (Private Chat)
| دستور | توضیح |
| :--- | :--- |
| `/start` | شروع کار با ربات و نمایش منوی اصلی |
| `/backup` | دریافت فایل بکاپ کامل دیتابیس (مخصوص مالکین ربات) |
| `/restore` | بازیابی فایل دیتابیس با ریپلای روی فایل `.db` (مخصوص مالکین ربات) |

### 👥 دستورات گروه (Group Commands)
| دستور | نحوه استفاده | توضیح |
| :--- | :--- | :--- |
| `/panel` | ارسال در گروه | باز کردن پنل مدیریت و تنظیمات پیشرفته گروه |
| `/warn` | ریپلای روی پیام | ثبت ۱ اخطار دستی برای کاربر |
| `/unwarn` | ریپلای روی پیام | حذف ۱ اخطار از کاربر |
| `/title [لقب]` | ریپلای روی پیام | اعطای لقب اختصاصی به کاربر (مثال: `/title سلطان`) |
| `/vip` | ریپلای روی پیام | افزودن کاربر به لیست اعضای ویژه (معاف از قفل‌ها) |
| `/unvip` | ریپلای روی پیام | حذف کاربر از لیست اعضای ویژه |

## 🚀 راهنمای استقرار و اجرا (Deployment)

این پروژه برای اجرا روی سرورهای ابری نظیر **Railway**، **Heroku** یا **VPS شخصی** کاملاً بهینه‌سازی شده است.

### 📁 ساختار فایل‌های پروژه:
- `bot.py`: سورس‌کد اصلی ربات
- `requirements.txt`: پیش‌نیازهای پایتون
- `Procfile`: دستور اجرای فرآیند پس‌زمینه در سرورهای ابری

### 🛠️ مراحل سریع اجرا روی Railway:
1. این ریپازیتوری را در حساب گیت‌هاب خود آپلود کنید.
2. توکن ربات (`TOKEN`) و آیدی عددی ادمین (`SUDO_ADMINS`) را در فایل `bot.py` تنظیم کنید.
3. در سایت **Railway.app** یک پروژه جدید ساخته و آن را به این ریپازیتوری متصل کنید.
4. پروژه به‌صورت خودکار Deploy شده و ربات آنلاین خواهد شد!
